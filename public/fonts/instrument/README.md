# Instrument typography

Selected site typography: Instrument Serif for editorial headings and Instrument
Sans for body text and controls. Both normal and italic styles are bundled locally
and loaded through `next/font/local` in `src/lib/typography.ts`.

- Instrument Sans: variable weight 400–700, Latin subset, Google Fonts version 4.
- Instrument Serif: regular weight 400, Latin subset, Google Fonts version 5.
- Fonts outside the bundled character coverage use the configured system fallback.
- The specialized license plate artwork font is managed separately.

Retrieved September 5, 2026 from the Google Fonts CSS API and `fonts.gstatic.com`:

https://fonts.googleapis.com/css2?family=Instrument+Sans:ital,wght@0,400..700;1,400..700&family=Instrument+Serif:ital@0;1&display=swap
